REVERIE SOUNDTRACK ASSETS

Extract this ZIP into the root of your Godot project (the folder containing project.godot).
The files will be placed under:
  assets/audio/music/

Track roles:
- crown_of_ash_and_rose.mp3 — title screen / main menu theme
- the_frozen_kingdom.mp3 — world exploration theme
- fading_into_the_void.mp3 — Ravienne & Cassie story theme

The project-side AudioDirector references these exact paths.
